Private project

Self-hosted trading software, built end to end.

In my private project I build a modular trading platform that runs entirely on a server of your own. Automated trading agents trade crypto, stocks and forex — each with its own capital and trading strategy, and each saying what it does and why.

  • Agents that explain themselves

    Every agent trades one strategy with capital of its own, and shows instrument by instrument what it decided and why.

  • Fourteen connectors

    Twelve crypto exchanges, Interactive Brokers and Alpaca, plus a simulator for paper trading — in process, or out of process as gRPC plugins.

  • Backtests with honest opponents

    A strategy is measured against holding its whole universe and against a random control, on the same prices and with the same costs.

  • Strategies in any language

    Built in, written as TypeScript or JavaScript scripts in the web app, or plugged in over gRPC with SDKs for C#, Python and TypeScript.

  • Web, Android and Windows

    A React web app, a Flutter phone app with push notifications and a Tauri tray app — all on the same agents and the same money.

  • Your server, your keys

    One Docker Compose stack with PostgreSQL, backups and OpenTelemetry. An optional MCP server lets AI assistants read market data — and trade only behind a second switch.

AI-assisted engineering

Built with AI, owned by an engineer.

Like most engineers today, I use AI to build new software and to extend existing codebases. Coding agents such as Claude Code explore unfamiliar code, draft implementations and tests, and carry a refactoring through hundreds of files. Most of my recent commits are co-authored by one. What makes that work is the discipline around it.

  • Context, written down

    Conventions, architecture notes and per-area rules live next to the code, so agents and people follow the same playbook.

  • Guardrails, not hope

    Hooks ask before anything reaches main, before a force push or a tag. Analyzers and CI catch the rest.

  • Tests define done

    A change is finished when it builds clean and its tests pass — whoever, or whatever, typed it.

  • Judgment stays human

    I decide the architecture and the trade-offs, read the diffs, and the merge button stays mine.
